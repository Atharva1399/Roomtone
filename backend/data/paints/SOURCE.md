# Paint colour books

From [jpederson/colornerd](https://github.com/jpederson/colornerd) (`json/` folder, branch `gh-pages`),
downloaded 2026-10-18. Each file is a list of `{name, label, hex}`.

- `sherwin-williams.json`
- `benjamin-moore.json`
- `farrow-ball.json`
- `behr.json`

Notes:
- The repo has no licence file. Fine as reference data for a student/hackathon project;
  check with the brands before any commercial use.
- Hex values are on-screen approximations published by the brands, not lab measurements.
  Real paint looks different under different light, which is why previews use the room's own lighting.
- No Indian brands (Asian Paints, Berger, Nerolac) are included. Adding one only needs a JSON
  file in the same format in this folder.
